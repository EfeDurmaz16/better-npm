## Design Notes

### #22 Parallel Resolution
Current: sequential npm/pnpm/yarn install subprocess.
New: `src/engine/resolver.js` — parallel `packument` fetches, semver resolution in Rust (NAPI), dedup.

- Batch registry requests: up to 64 concurrent
- Coalesces duplicate version fetches within a run
- Falls back to pm CLI if NAPI resolver produces inconsistent tree

### #23 Prefetch Hints
`better prefetch [--watch]`

- Parses `scripts` in `package.json` to extract tool names (jest, eslint, tsc, etc.)
- Emits list of packages likely needed; pre-populates CAS store
- `--watch` mode: fs-watch on `package.json`, auto-prefetch on change

### #24 CI Cache Pack
`better cache pack [--output path.tar.zst]`
`better cache unpack [--input path.tar.zst]`

- Exports CAS store + reuse markers as a single compressed archive
- Designed for CI layer caching (GitHub Actions cache, CircleCI cache)
- Includes integrity manifest for partial restore

### #25 Registry Mirror Auto-select
On first run (or `better doctor`): probes latency of known mirrors (registry.npmjs.org, registry.npmmirror.com, etc.).
Persists fastest mirror in `~/.better/config.json`.
Respects `.npmrc` `registry=` override.
