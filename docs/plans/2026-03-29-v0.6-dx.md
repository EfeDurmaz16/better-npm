## Design Notes

### #26 Delta Updates
On `better install` after lockfile change:
- Diff current lockfile vs stored snapshot
- Only re-materialise packages whose CAS entry changed
- Unchanged packages: verify inode still points to CAS (fast path)
- Speedup for large monorepos: skip 90%+ of packages on typical dep update

### #27 Workspace Topology Cache
`~/.better/workspace-topo/<project-root-hash>.json`

- Caches computed DAG (packages, deps, versions)
- Invalidated when any `package.json` in the workspace changes (mtime check)
- Avoids re-scanning entire workspace on every `better workspace` invocation

### #28 Interactive Update Wizard
`better update --interactive` (alias: `better up`)

Full-screen TUI:
- Table of all outdated deps (patch/minor/major color-coded)
- Arrow keys to navigate, Space to toggle selection
- Shows changelog snippet inline
- Enter to apply selected updates

### #29 Shell Completions
`better completions [bash|zsh|fish]`

Generates completion scripts. Auto-installs via `better completions --install`.

### #30 `better init` Wizard
`better init` (already partially implemented via Phase C templates)

Enhance with:
- Interactive prompts (name, license, private, workspace)
- Opinionated defaults: .gitignore, .npmrc, SECURITY.md
- Policy file scaffold
- Hooks config scaffold
