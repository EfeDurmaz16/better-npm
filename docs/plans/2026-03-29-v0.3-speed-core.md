## Design Notes

### better.lock.json (#12)
Stored alongside `package-lock.json`. Contains:
- `kind`: `"better.lock"`
- `version`: schema version
- `lockHash`: SHA-256 of the underlying lockfile
- `fingerprint`: install fingerprint (node_modules snapshot hash)
- Timestamps and install metadata

### Engine Trait System (#16)
`src/engine/interface.js` — abstract base class with:
- `resolve(projectRoot, opts)` → resolution plan
- `install(projectRoot, plan, opts)` → materialise
- `verify(projectRoot, opts)` → integrity check

Concrete implementations:
- `NpmEngine` — wraps npm CLI
- `PnpmEngine` — wraps pnpm CLI
- `YarnEngine` — wraps yarn CLI
- `BetterEngine` — pure Rust via NAPI

### Install Progress TUI (#17)
`src/tui/installProgress.js` — replaces plain `commandLogger.info` progress calls.
Phases: resolve → fetch → extract → link → bins → done
Each phase shows elapsed time and item count.

### Lockfile Merge Driver (#13)
`bin/better-merge-driver.js` — invoked by git as:
```
better-merge-driver %O %A %B %P
```
Strategy: union merge on packages dict; conflict → keep OURS + annotate.
`.gitattributes` snippet:
```
better.lock.json merge=better-lock
```
