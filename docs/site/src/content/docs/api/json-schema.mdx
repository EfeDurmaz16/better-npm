---
title: JSON API Reference
description: Machine-readable JSON output schema for all better commands
---

All better commands support `--json` for machine-readable output.

## Envelope Format

```json
{
  "ok": true,
  "kind": "better.<command>",
  "schemaVersion": 2,
  ...command-specific fields...
}
```

## Commands

### better audit

```json
{
  "ok": true,
  "kind": "better.audit",
  "schemaVersion": 2,
  "vulnerabilities": [
    {
      "id": "GHSA-xxxx-xxxx-xxxx",
```

## Error Response

```json
{
  "ok": false,
  "kind": "better.<command>",
  "error": "description of what went wrong"
}
```

## Semantic Exit Codes (Agent Mode)

When running with `better agent <cmd>` prefix or `BETTER_AGENT=1`, exit codes are:

| Code | Meaning |
|------|---------|
| `0` | Success |
| `1` | Dependency error |
| `2` | Security blocked |
| `3` | Policy failure |
| `4` | Network error |
